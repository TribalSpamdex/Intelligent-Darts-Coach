# DEV55 historical retention

Baseline: Dev54 merge `1321f09fd7c811a14c52e4ed6e171a50761fffd7`.

The oldest eligible complete calendar month must be more than 24 months old; one batch contains at most six calendar months and never touches the most recent 18 months. The complete original profile is exported and read back byte-for-byte, and the candidate is regenerated synchronously under the existing exclusive writer before the atomic primary replacement. A stale preview, mismatched backup, unavailable writer, failed primary write or a non-shrinking compressed primary refuses the operation. There is no unattended deletion. Settings notifies the player when an eligible batch exists.

Historical monthly summaries retain native skill totals and denominators, fixed practice and exact-target statistics, validated contextual Quick Play and exact-finish counts by setting, recorded game counts, scoring milestones and game personal records. Progress lifetime counts, Records and historical monthly reports use these separately from raw detail. No historical summary is replayed as a measurement or used as current calibration, intervention compliance, learning dose or match data. Other detailed views only use remaining raw records. Assessment mirrors, old ambiguous/unlinked records, intervention baseline/review windows and separate coach memory (including actual legs, equipment and outcomes) are preserved. The original exported backup is the only way to recover pruned raw records; restoring it replaces the current profile, so retain newer backups too. A current active session, proposed/accepted intervention or active experiment blocks consolidation. The primary storage format and two-generation manual archive remain unchanged. No claim of unlimited storage, automated migration, or complete long-term historical causal evaluation is made.

The new browser test exercises wrong backup, changed profile, failed primary write, historical statistics, successful commit and reload. The actual Dev54 upgrade is added to the prior pinned upgrade cases. Full CI must pass before release.
