- Independent engine: pinned V0.4.0 at TribalSpamdex/DCI-independent commit a39210419869ecf1160471997b10300d57c93ef1. The original engine regression suite is carried over.
- Adapter projects completed native assessment measurements, fixed scoring and bull rounds, and confirmed non-quick daily Big Singles into separate protocols. Host observations and classified practice minutes are projected from saved records, not duplicated. Corrected or missing baseline measurements veto an accepted intervention. The independent engine may transfer five minutes within a scheduled session only when current evidence, explicit acceptance, unchanged baseline, existing workload protections, and absence of any competing legacy adjustment permit it. The legacy planner retains control otherwise. No change to game rules or levels.
- No original storage keys or original app source are modified. IDC has separate local storage. No automatic import of existing personal data. No automatic import of another app's personal data. The independent profile is included in IDC backups and is removed by IDC's reset. No cross-device or concurrent-window guarantee beyond the existing host storage design.
- No LLM or paid runtime services. Actual player outcomes and iPhone tests remain necessary.

No automatic changes to legacy game selection or difficulty.
- Checkout alternatives preserve shortest legal dart count and only compare evidence on the final double; not calibrated full-route probabilities. Unmeasured first darts, recovery, competition pressure and miss positions remain unknown. Use with caution. No new source repositories or external services.
- The broader language interface is still deterministic and read-only, not unrestricted conversation. Real player effectiveness and iPhone behaviour require testing.

## V1.5.0 precision adaptive progression
- 33 scoring and first-nine measurement bands: [0,20), then five-point bands through the inclusive 180 maximum. Accuracy-based measured skills use 40 bands of 2.5 percentage points. These statistical bands are separate from the original seven private gameplay tiers. The four native gameplay skill systems each have two internal subdivisions (14 possible per skill); no stored tier number or old game difficulty key is migrated.
- Optional fixed scoring, doubles, checkout, bull, singles and treble checks are recorded independently of native assessments and scheduled practice. Each has a fixed complete protocol and denominator, one saved record per skill and date, explicit confirmation, validation and removal. The native coaching system does not infer unmeasured skills from the self-reported scoring average.
- A harder subdivision needs at least eight distinct days, three recent seven-day blocks, sufficient attempts, a fresh last measurement and support in both independent chronological halves. A contradictory adequate fixed protocol vetoes escalation. Provisional thresholds are conservative engineering policies, not statistical significance claims. Removing or editing evidence recomputes results; no negative public tier notifications.
- At round construction, supported games may receive one bounded harder adjustment (scalar target/goal, dart budget, scoring ladder, etc.) without changing rings, victory semantics, timer or existing tier. Beginner safety, legacy recovery and tuning, standard probes, recent failed-day cooldown, trial isolation, readiness and fixed benchmarks take precedence. Quick Play, extra practice and unsupported or infeasible configurations remain unchanged. The modified rule is saved with the round; it is excluded from standard pressure forecasts and legacy skill samples. No in-progress round is changed. A new exercise recalculates from saved data, while the measured decision is frozen within the current exercise.
- Starting-average selection uses 33 visible choices with legacy values retained for existing backups. 501 provisional allowances interpolate the previous anchor values; new casual bots use adequately sampled fixed scoring evidence or a reported starting average, with normalized scoring outcome probabilities. These are not calibrated predictions of actual match strength. Old casual bot sessions keep their prior algorithm. Original V6.2 and the pinned independent engine remain unchanged.
- Progress shows positive confirmed milestones; Coach provides detailed current median, next confirmation target, evidence denominators and separate standard/personalised challenge reports. No visible internal tier labels. Browser verification includes native game configuration construction and persistence/offline smoke testing; actual physical iPhone and field efficacy testing remain outstanding.
